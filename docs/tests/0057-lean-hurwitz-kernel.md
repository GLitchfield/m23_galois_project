# Test 0057: Lean Hurwitz kernel and 8A summary certificate

## Question

Can a pinned Lean 4 project independently check the stable algebraic core of
the braid calculations and bind the finite conclusion of test 0056 to its
committed TSV without unfinished proofs or a native-evaluation shortcut?

## Inputs and provenance

- implementation: the commit containing this note;
- Lean `4.29.1`;
- mathlib tag `v4.29.1`, resolved commit
  `5e932f97dd25535344f80f9dd8da3aab83df0fe6`;
- pinned transitive dependency revisions in `formal/lake-manifest.json`; and
- source certificate
  `data/derived/m23_8a_small_component_descent.tsv`, generated by test 0056.

The formal development is project-owned. Mathlib and its dependencies retain
their upstream licenses and are materialized under ignored `formal/.lake/`.

## Method

The abstract files work over an arbitrary group. Lean checks the product and
inverse formulas for the adjacent Hurwitz move, the Artin braid relation,
compatibility with simultaneous conjugation, and equality of the subgroups
generated before and after the move.

For the prefix-conjugated inverse formula used in test 0056, Lean proves

```text
product(conjugateAux(prefix, tuple))
  = prefix * product(tuple)^-1 * prefix^-1
```

and proves that applying the operation twice returns the original list. The
product-one preservation theorem is a direct corollary.

A deterministic Python generator reads the committed TSV and emits
`Test0056Data.lean`. The check compares a fresh generation byte-for-byte with
the committed module. Lean's ordinary kernel evaluator (`by decide`) then
proves:

- the 14-component map is an involution;
- its fixed points are exactly zero-based IDs 2 and 5, corresponding to the
  one-based IDs 3 and 6 in test 0056;
- the 28-symmetry-orbit map is an involution; and
- it has no fixed point.

The check rejects `sorry`, `admit`, project `axiom` declarations, and
`native_decide`. It also compiles a dedicated audit file that prints the axioms
of every headline theorem.

Run:

```sh
make check-lean
```

## Result

Passed. All modules compile. The audit reports only the expected foundational
assumptions `propext`, `Classical.choice`, and `Quot.sound`, with the latter two
appearing only where the subgroup-closure library requires them. No project
axiom, unfinished proof, or native decision axiom occurs.

## Boundary and verdict

This was the first formal seam. Lean verified the algebraic formulas and the
logical content of the committed finite table. At this experiment's commit it
did not yet verify the GAP computation that placed each conjugated degree-23
tuple in the recorded target component, and it did not formalize the geometric
branch-cycle theorem. Test 0058 subsequently closed the tuple-assignment seam.

Passed as the formal-kernel foundation. The proposed degree-23 witness
extension was completed in test 0058.
