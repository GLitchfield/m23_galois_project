# Test 0060: collapse of the 8A lifting invariant

## Question

Can the universal lifting invariant for components with local monodromy in
`8A` distinguish either of the two full components that survive complex
conjugation?

## Published theorem boundary

Section 4.1 of Béranger Seguin, *Fields of Definition of Components of
Hurwitz Spaces* ([arXiv:2303.05903](https://arxiv.org/abs/2303.05903), accepted
for publication in 2025), uses the group `U(H,c)` generated by symbols `[g]`
for `g` in a rational conjugation-invariant subset `c`. The product of these
symbols is constant on braid components. Its product-one subgroup has the
structure

```text
U1(H,c) = H2(H,c) x ker(Z^D -> H_ab),
```

where `D` is the set of conjugacy classes contained in `c` and `H2(H,c)` is a
quotient of the Schur multiplier. Seguin cites the Ellenberg--Venkatesh--Westerland
and Wood component theory for this structure and for the universality of the
invariant among group-valued multiplicative invariants.

## Specialization to M23 and 8A

Take `H = M23` and `c = 8A`.

- `M23` is nonabelian simple, hence perfect, so `H_ab` is trivial.
- The ATLAS M23 page records `Mult = 1`, so the Schur multiplier and
  its quotient `H2(H,c)` are trivial.
- `c` consists of one conjugacy class, so `Z^D` is `Z`.

Consequently `U1(M23,8A)` is isomorphic to `Z`, with the remaining coordinate
equal to the number of entries in class `8A`. Every component considered here
has four entries, so every `(8A)^4` component has the same invariant, `4`.

## Result and verdict

The lifting invariant cannot distinguish any of the fourteen components, in
particular components 3 and 6. Because this invariant is universal among
group-valued multiplicative invariants on the relevant component monoid, no
alternative invariant of that same formal kind can recover the missing
separation.

This is a theorem-based negative result, not a determination of the Galois
action. It does not prove that components 3 and 6 are conjugate, individually
defined over `Q`, or not defined over `Q`. Seguin's Section 2.3.4 also shows
that marked and connected-unmarked components have the same field of
definition when their monodromy is the full group, as it is here. Together
with test 0059, this leaves an explicit non-multiplicative Galois action on the
Nielsen components or equations for the relevant Hurwitz objects.
