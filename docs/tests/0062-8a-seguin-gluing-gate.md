# Test 0062: the Seguin gluing gate for class 8A

## Question

Can Seguin's theorem producing `Q`-defined glued components turn the known
small `(8A)^4` components into a theorem-backed four-branch route?

## Published theorem and the tempting analogy

Seguin's Theorem 5.4 says that if two components `x,y` are defined over a
number field `K`, then the generating gluing set `ni^natural(x,y)` contains a
component defined over `K`.  Example 5.5 applies this to `M23`: an inverse
pair of order-3 elements is a `Q`-defined cyclic component, and two suitable
conjugates generate `M23`, producing a `Q`-defined four-branch component.

It is tempting to replace `3A` by the rational class `8A`.  That substitution
does not preserve the premise of the theorem.

## Cyclotomic audit

Let `a` have order 8.  In the cyclic group generated by `a`, the rational
power orbit is

```text
a, a^3, a^5, a^7.
```

Seguin's Example 2.13, equivalently the abelian case of the branch-cycle
lemma, says that a cyclic component is defined over `Q` exactly when its
multiset is invariant under these unit powers.  The two-entry inverse pair
`(a,a^-1) = (a,a^7)` omits `a^3` and `a^5`, so it is not `Q`-defined.  The
smallest balanced product-one block is the four-entry tuple
`(a,a^3,a^5,a^7)`.

Thus Theorem 5.4 applied to two conjugate cyclic `8A` blocks first gives an
eight-branch component.  It does not imply that any `(8A)^4` component is
defined over `Q`.  The difference from order 3 is exactly `phi(8)=4` versus
`phi(3)=2`.

## Direct check on the fourteen small components

As a separate finite check, GAP, Python, and Lean inspect all 168 certified
tuples in the 14 small components.  No tuple admits any of the three
partitions into two inverse pairs.  Hence none of these inner braid orbits is
even the direct two-inverse-pair gluing locus suggested by the analogy.

## Verdict

The theorem is relevant but does not settle components 3 or 6.  It supplies
a rigorous eight-branch `8A` construction principle, while the four-branch
small-component descent problem still requires genuinely non-cyclotomic
Galois data or equations.

This audit prevents two overclaims:

1. rationality of the ambient `M23` class `8A` does not make the cyclic
   inverse-pair component rational; and
2. Seguin's order-3 four-branch example cannot be transferred unchanged to
   order 8.
