# Test 0099: Seguin `(3A)^4` marked-to-inner reconciliation

## Question

Which of the two known full `(3A)^4` inner braid components contains
Seguin's four-branch construction, and what does his existence theorem imply
about their fields of definition?

## Convention lemma

Seguin's `Comp(G)` is the set of ordinary braid-group orbits of product-one
tuples before simultaneous conjugation (Section 2.2.4).  Häfner instead
computes on the inner quotient by simultaneous `G`-conjugation.

For a tuple `g` that generates `G`, these component sets are naturally
bijective.  Surjectivity is immediate.  For injectivity, Seguin's Proposition
2.4(iv) says that `g` and `g^gamma` are braid equivalent for every
`gamma` in the group generated by `g`, hence for every `gamma` in `G`.
Therefore two marked braid orbits whose images meet in the inner quotient
were already the same marked orbit.  This is a component-level statement;
the marked tuple orbit itself is `|G|` times larger because `M23` is
centerless.  The quotient that forgets the marking is defined over `Q`, so
this bijection is Galois-equivariant; Seguin Section 2.3.4 states directly
that the marked and connected-unmarked fields of definition agree.

Because all four classes are `3A`, the ordinary adjacent braid generators
`q2,q3,q4` give the full braid action relevant to Seguin.  This corresponds
to Häfner's symmetric homogeneous-class calculation, not merely his pure
ordered-class action.

The load-bearing source statements have been checked in the accepted paper,
not inferred from its introduction:

| Project bridge | Accepted-paper location | Scope used here |
| --- | --- | --- |
| marked components are ordinary braid orbits | Proposition 2.5 and Section 2.2.4 | product-one tuples before simultaneous conjugation |
| generated-group conjugation stays in a marked braid orbit | Proposition 2.4(iv), including its stated special case | injectivity of marked-to-inner on generating tuples |
| marked and unmarked fields agree for connected covers | Section 2.3.4 | Galois-equivariant transfer when the monodromy group is all of `G` |
| a rational component occurs in the gluing set | Theorem 5.4 | existence of a fixed marked component |
| the `M23` application has four branches and full monodromy | Example 5.5 | a component of connected `M23` covers in `(3A)^4` |

In particular, Example 5.5 explicitly checks that `a` and `a^h` generate
`M23` and describes the resulting component as connected.  The fixed
component therefore belongs to the same generating two-component set
enumerated below; it is not a possibly disconnected component outside that
set.

## Exact computation

The GAP program starts with the permutations `a,h` printed in Seguin's
Example 5.5 and the tuple

```text
(a, a^-1, a^h, (a^h)^-1).
```

It fixes the first entry `a`, canonicalizes by the order-180 centralizer
`C_M23(a)`, and traverses the actual adjacent Hurwitz generators
`q2,q3,q4`.  It then exhausts the 56,672 possible second elements of `3A`
as 356 centralizer orbits.  For every orbit representative `b`, GAP checks
whether `<a,b> = M23` and, if so, assigns
`(a,a^-1,b,b^-1)` to one of the two computed braid components.

This produces 40 generating centralizer orbits, all of size 180.  The
`β₃,η₂₃,η₂₃₄` permutation triple is also constructed on each component and
Riemann--Hurwitz computes its symmetric genus:

| Component | Inner full-braid size | Marked tuple-orbit size | Computed symmetric genus | Inverse-pair orbits | Second generators |
| --- | ---: | ---: | ---: | ---: | ---: |
| Seguin's printed `h` | 28,980 | 295,623,820,800 | 1,206 | 28 | 5,040 |
| Other component | 8,316 | 84,831,183,360 | 325 | 12 | 2,160 |

The other 316 centralizer orbits, containing 49,472 second elements, do not
generate `M23`.  Thus both components contain inverse-pair gluing tuples;
the unknown conjugator in Seguin's theorem cannot be recovered merely from
that tuple shape.

The computed component sizes sum to 37,296.  Test 0100 independently
materializes the complete product-one inner class from exact pair blocks and
finds exactly 37,296 generating classes, so the two traversals exhaust the
Nielsen class without using Häfner's reported global total.  The program here
independently verifies the two orbit closures, generation at every traversed
vertex, the class and product-one conditions, the complete centralizer-orbit
partition, and all 40 assignments.  Test 0100's product-order-1 row
independently recovers the same 40 generating inverse-pair classes.

## Galois conclusion

The marked-to-inner bijection removes the apparent convention gap.
Seguin's Theorem 5.4 and Example 5.5 prove that at least one connected marked
component in this Nielsen class is fixed by the absolute Galois group.
The class `3A` is rational (`a^-1` is in the same class, the only nontrivial
unit power for order 3), so the entire two-component passport is Galois
stable.  An action on a two-element set that fixes one element fixes the
other.  Therefore:

> Both full `(3A)^4` components are defined over `Q`.

In particular the component containing Seguin's printed `h` tuple is defined
over `Q`, even though the nonconstructive conjugator from the proof is
unknown.

This is a field-of-definition result for components.  It does not produce a
`Q`-rational point, equations, a regular `M23/Q(t)` cover, or an `M23`
number field.  The genera 325 and 1,206 make rational-point work difficult
but do not imply that rational points are absent.

Lean kernel-checks the finite final step in
`formal/M23Formal/Certificates/Test0099.lean`: every permutation of a
two-element set with one fixed point fixes both elements.  It also checks the
component-size and inverse-pair count identities.  The formal statement
deliberately takes the mathematical and computational premises as inputs;
it does not formalize Seguin's theorem, rationality of the passport, or the
GAP exhaustiveness certificate.
