# Test 0003: the `(15A,2A,2A,2A)` orbit

## Question

Does the reusable fixed-first-coordinate engine reproduce Häfner's second
quadratic-field case: 90 inner Nielsen classes in one pure braid orbit with the
reported genus-zero symmetry action?

## Method

The method is the same as test 0002, now run for both natural-action classes of
order 15. The shared implementation in `src/gap/m23_fixed_first.g` enumerates
product-one tuples, quotients by the centralizer of the fixed first coordinate,
filters for generation of M23, computes the pure braid action, and evaluates
the symmetry operators.

Run:

```sh
make reproduce-15a-orbit
make test
```

## Result

Both computed order-15 classes give identical results:

- 3,150 product-one tuples after fixing the first coordinate;
- 210 simultaneous-conjugacy orbits before generation is imposed;
- 90 generating inner Nielsen classes;
- one transitive pure `B4` orbit of size 90;
- pure-generator cycle shape `2^4 3^19 5^5` for each of `beta12`, `beta13`, and
  `beta14`;
- pure braid genus 4;
- `beta3` cycle shape `3^1 4^2 5^5 6^9`;
- `eta23` cycle shape `2^45`;
- `eta234` cycle shape `3^30`;
- symmetric genus 0.

The Nielsen count, three symmetry cycle shapes, and symmetric genus reproduce
Häfner's theorem exactly. As in test 0002, testing both computed classes avoids
an unsupported assignment to ATLAS `15A/15B`.
