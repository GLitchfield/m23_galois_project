# Test 0002: the `(14A,2A,2A,2A)` orbit

## Question

Can we independently reproduce Häfner's claim that the inner Nielsen class for
`(14A,2A,2A,2A)` has size 84, is one pure `B4` orbit, and has the reported
symmetry action of genus zero?

## Method

For each of the two computed natural-action conjugacy classes of order 14:

1. Fix an order-14 representative `s1`.
2. Enumerate pairs `(s2,s3)` of the 3,795 involutions and derive
   `s4=(s1*s2*s3)^-1`.
3. Retain product-one tuples with `s4` an involution.
4. Quotient by simultaneous conjugation under `C_M23(s1)`, then retain only
   tuples generating all of M23.
5. Compute the actions of `beta12`, `beta13`, and `beta14`, normalizing the first
   coordinate after each move.
6. Independently compare the direct pure-braid formulas with compositions of
   elementary forward/inverse Hurwitz moves and check a braid relation.
7. Compute the symmetry actions `beta3`, `eta23`, and `eta234` and their genera.

Run:

```sh
make reproduce-14a-orbit
make test
```

## Result

Both computed order-14 classes give identical results:

- 3,724 product-one tuples after fixing the first coordinate;
- 280 simultaneous-conjugacy orbits before generation is imposed;
- 84 generating inner Nielsen classes;
- one transitive pure `B4` orbit of size 84;
- pure braid genus 1;
- `beta3` cycle shape `3^1 4^3 5^3 6^9`;
- `eta23` cycle shape `2^42`;
- `eta234` cycle shape `3^28`;
- symmetric genus 0.

The last four values exactly reproduce Häfner's theorem. Running both order-14
classes avoids assigning the natural-action class numbers 14 and 15 to ATLAS
`14A/14B` without a verified fusion.

The 280 unfiltered product-one orbits do not contradict the normalized
structure constant 266. The latter is a character-theoretic weighted count and
Häfner uses its floor only as an upper bound for the number of generating inner
classes; it is not the raw count of all simultaneous-conjugacy orbits.
