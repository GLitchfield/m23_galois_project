# Test 0063: three-point boundary incidence for the small 8A components

## Question

If pair-product classes and pair-generated subgroup orders do not distinguish
the fourteen small `(8A)^4` components, does the exact inner Nielsen class of
each ordered boundary pair retain the missing information?

For a pair `(g_i,g_j)`, the associated three-point degeneration has branch
cycles

```text
(g_i, g_j, (g_i*g_j)^-1).
```

Its simultaneous-conjugacy class records more than the conjugacy class of the
node inertia `g_i*g_j` or the abstract group generated by the pair.

## Method

GAP evaluates all six pairs at every vertex of every full component.  It
records:

- the exact order of `g_i*g_j`;
- the order of `<g_i,g_j>`;
- a deterministic ID for the ordered-pair inner conjugacy class; and
- the image of that class under prefix-conjugated inversion of the associated
  product-one triple.

There are `14 * 12 * 6 = 1,008` incidence records.  The IDs are assigned after
lexicographically sorting the canonical degree-23 pair representatives.  The
Python verifier checks the complete incidence domain and the resulting
complex-conjugation involution.  GAP separately tests every simultaneous
conjugacy and all generated subgroup orders.

The ordered degree-12 braid-action isomorphisms from test 0059 are then tested
at three levels: pair-product order, pair-generated subgroup order, and exact
ordered-pair inner class.  For the last level, every possible braid-action
transporter is considered, using the centralizer of the ordered generator
triple rather than relying on GAP's first transporter.

Run:

```sh
make reproduce-8a-small-orbits
make test
```

## Result

The subgroup-order refinement still collapses.  Every component has

```text
12 boundary pairs generating C8
60 boundary pairs generating M23
```

and the braid-action transporters preserve those orders vertex by vertex.

The exact three-point inner classes do not collapse.  The 1,008 incidences use
57 ordered-pair inner classes:

- one cyclic class with pair product in `4A`;
- 28 generating classes with pair product in `2A`; and
- 28 observed generating classes with pair product in `4A`.

Complex conjugation fixes the cyclic class and swaps the 56 generating
classes in 28 pairs.  No generating three-point class is real.

After exact pair-inner-class labels are attached, the fourteen ordered braid
actions lie in fourteen distinct labeled-action classes.  In particular,
components 3 and 6 now have different finite incidence data.

## Arithmetic interpretation and boundary

This is the first tested finite enrichment that distinguishes the two real
survivors, but it is not by itself a descent proof.  Absolute Galois can
permute the zero-dimensional three-point inner classes, so their numeric IDs
are not individually rational labels.  Cau's degeneration theorem says that
Galois must preserve the incidence relation while applying its action to
those boundary components.

Test 0064 sharpens this conclusion and corrects an implicit completeness
assumption in the first version of this note.  The 28 observed `4A` labels are
not the complete `(8A,8A,4A)` Nielsen class: there are 4,208 generating inner
classes globally.  Fortunately, the exact labels from the complete 28-element
`(8A,8A,2A)` class alone still put the fourteen braid actions in fourteen
distinct labeled-action classes.  The remaining four-branch problem can
therefore be reduced to determining the Galois action on that one complete,
Galois-stable 28-element set and propagating it through the committed
incidence table.  Complex conjugation is already explicit; the rest of the
Galois action remains unknown.

This makes equations for the relevant three-point covers, or a primary source
that identifies their fields of definition, the next useful input.  More
unlabeled invariants of the twelve-point braid representation are unlikely to
help.
