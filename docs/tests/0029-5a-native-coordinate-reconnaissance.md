# Test 0029: 5A native-coordinate reconnaissance

## Question

Does the native coordinate design developed on 4A generalize to a real
generating 5A quotient vertex, and how large is the 5A global normalization
payload?

## Inputs and provenance

- implementation: `c209e47422fb5e5f4976c6cfda86d12689a92d95`;
- regenerated schema-v2 5A pair checkpoint: SHA-256
  `1d6653fedb4327ed4594a1ca55cad03b82fbcae5a45817dbadeede05902468ea`;
- certified bridge shard 1 of 16: SHA-256
  `d42a4b013630a40e65643cff45623f0513aa6acba7e54f5de5a4f5be466beee0`;
- GAP 4.12.1 and g++ 13.3.0.

The schema-v2 checkpoint is reproducible with:

```bash
./scripts/generate-homogeneous-pair-orbits.sh 5 runs/5a-pair-orbits-v2.g
```

The committed census is independently regenerated by:

```bash
make check-native-5a-census
```

## Method

The exact census script counts the target-pair and class-specific right-pair
rows implied by the pair checkpoint. The native fixture exporter was extended
to accept a certified bridge checkpoint, translate its first generating member
to the homogeneous class vector, locate its pair-twist coordinate, and export
all source tuples, beta13/beta14 images, table rows, destination coordinates,
weights, ordering, and deduplication data.

The existing C++ coordinate checker was compiled without a 5A-specific code
path and run on that generated fixture. The schema-v2 fixture export was also
timed once with `/usr/bin/time` while the resource-capped 4A scan was resident.

## Result

The 5A global layer contains:

| table | rows | current raw layout |
| --- | ---: | ---: |
| target-pair normalization | 680,064 | 68,006,400 bytes |
| right-pair transport | 823,048 | 63,374,696 bytes |
| total | 1,503,112 | 131,381,096 bytes |

The checkpoint has 45,344 pair orbits and 161,177,452 symbolic macroblocks.
The global 131.4 MB layer is therefore practical to serialize or keep in RAM;
the per-macroblock relative maps and refinements must remain lazy.

The certified bridge seed located at block 71,532,995, twist vertex 3. Its
weight is 5 and its ten beta13/beta14 images deduplicate to six ordered
neighbors. C++ reproduced every exported coordinate and neighbor exactly.
The schema-v2 GAP export took 42.73 seconds and 555,080 KiB maximum RSS in the
single timed sample.

## Limits and next gate

This proves one real 5A coordinate micro-checkpoint, not an end-to-end 5A BFS,
throughput projection, or GPU speedup. Stored schema-v2 normalizers also choose
a checkpoint-bound coordinate convention that can differ from the old
schema-v1 fallback while describing the same exact quotient. All future 5A
artifacts must therefore record the pair-checkpoint hash.

The next native gate is a versioned binary export of the global tables followed
by isolated 5A refinement and small-walk profiles. A GPU prototype remains
conditional on finding a uniform batch kernel after that profile.

## Verdict

Passed the initial class-generalization and memory-feasibility gates.
